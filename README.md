# My Templater

Расширение для браузеров на базе Chromium, для мгновенного сохранения и использования текстовых шаблонов.

---

## Установка

1. Скачай последний релиз `chrome-mv3-prod.zip` со страницы [Releases](https://github.com/AtinsS/my-templater/releases) и распакуй архив.
2. Открой страницу расширений своего браузера:
   - **Chrome:** `chrome://extensions`
   - **Яндекс Браузер:** `browser://extensions` или `yandex://extensions`
   - **Microsoft Edge:** `edge://extensions`
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение** (в Edge — **Загрузить распакованное**) и выбери распакованную папку `chrome-mv3-prod`.
5. Если появится предупреждение о расширениях из других источников, подтверди установку.

После установки расширение появится на панели расширений браузера.

---

## Как пользоваться

Клик по иконке расширения открывает список шаблонов.

Действия:
* **Создать:** Кнопка "+ Новый"
* **Скопировать:** Кнопка копирования на карточке — текст уходит в буфер обмена.
* **Изменить:** Кнопка карандаша → правь поля → «Сохранить» 
* **Удалить:** Кнопка корзины → подтверди удаление
* **Найти:** Строка поиска сверху — ищет и по названию, и по тексту 

### Контекстное меню — быстрое сохранение

1. Выдели текст на любой странице.
2. ПКМ → **«💾 Сохранить как шаблон»**.
3. Появится уведомление — шаблон добавлен.

Название шаблона будет таким же, как выделенный фрагмент — потом можешь переименовать.

## Бэкапы

Кнопки экспорт и импорт сохранят шаблоны в формат JSON, чтобы их не потерять. 

> [!important] Важно!
> Рекомендуется делать бэкапы хотябы раз в неделю/месяц.


---

## Где хранятся данные

Шаблоны лежат в `chrome.storage.local` браузера и данные никуда не передаются.  
Синхронизация между устройствами не предусмотрена. Очистка данных расширения — это потеря шаблонов.

## Стек

- **Язык:** TypeScript 5.3
- **UI-библиотека:** React 18
- **Фреймворк расширений:** Plasmo Framework
- **API браузера:** Chrome Extensions API
- **Тестирование:** Vitest + React Testing Library + JSDOM
- **Качество кода:** Prettier с автоматической сортировкой импортов
